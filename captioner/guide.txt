See README.md for setup, known limitations, and the simplified workflow.

Existing timestamped transcript workflow (from this directory):
python3 captioner_cli/transcribe.py ~/Downloads/Timeline\ 1.mp3 ~/Downloads/Timeline\ 1.txt

Optional plain Roman Hinglish transcript workflow:
python3 -m pip install -r requirements-alignment.txt
python3 captioner_cli/transcribe.py ~/Downloads/Timeline\ 1.mp3 ~/Downloads/Timeline\ 1.txt --engine stable-ts --language hi

Output is Timeline 1.words.srt. Existing files require --overwrite.
The plain-text backend is experimental: compare it against an actual reel before relying on it.
